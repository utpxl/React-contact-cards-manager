# React Contact Cards Manager

A responsive single-page React application for creating, displaying, and searching digital contact/business cards.

## Features

- Add new contacts dynamically
- Display contacts in a responsive card layout
- Real-time search by name or company
- Reusable component-based structure
- Modern UI with hover effects and clean styling

## Technologies Used

- React (Functional Components + Hooks)
- JavaScript (ES6+)
- CSS

## Components

- **App** – manages state and composition
- **ContactForm** – handles user input and submission
- **ContactList** – renders all contact cards
- **ContactCard** – reusable card component

## Functionality

- Controlled form inputs
- Dynamic rendering without page refresh
- Case-insensitive filtering of contacts
- Responsive layout for desktop and mobile devices
